Rozdíl mezi charakteristikami středu a variability

Author

Filip Děchtěrenko

Published

September 20, 2025

Modified

December 6, 2025

Úvod

V deskriptivní statistice používáme při popisu statistických dat charakteristiky středu a charakteristiky variability.

Charakteristika středu

Co je charakteristika středu?

Charakteristika středu je způsob, jak shrnout velké množství dat pomocí jednoho čísla, které představuje “střed” nebo “typickou hodnotu” datové sady. Nejčastěji používanou charakteristikou středy je průměr. Dalšími klasickými ukazateli středu jsou medián a modus.

Průměr

Průměr je součet všech hodnot datové sady vydělený počtem hodnot. Je to velmi intuitivní a snadno pochopitelná statistika.

Příklad z běžného života: Představte si, že chcete zjistit průměrnou výši kapesného, které dostává vaše skupina přátel. Sečtete tedy všechnu obdrženou částku peněz a vydělíte počtem přátel.

Medián

Medián je střední hodnota datového souboru, když jsou všechny hodnoty seřazeny od nejmenší po největší. Je užitečný zejména tehdy, jsou-li v datech extrémy, které mohou zkreslit průměr.

Příklad z běžného života: Pokud seřadíte své známky od nejhorší po nejlepší, medián bude hodnota uprostřed vašeho seznamu.

Modus

Modus je hodnota, která se v datové sadě vyskytuje nejčastěji. Může být více než jedna, pokud se více hodnot vyskytuje stejně často.

Příklad z běžného života: V anketě o oblíbenou chuť zmrzliny může být nejčastější odpovědí čokoládová zmrzlina. Ta je tedy modem.

Charakteristika Variability

Co je charakteristika variability?

Charakteristika variability nám říká, jak moc se data liší od sebe navzájem a od středové hodnoty. Variabilita je důležitá, protože nám poskytuje kontext při interpretaci charakteristiky středu. Hlavními ukazateli variability jsou rozptyl, směrodatná odchylka a variabilita (rozpětí).

Rozptyl

Rozptyl vyjadřuje průměrnou odchylku každé hodnoty od průměru datové sady. Vypočítá se jako průměr čtverců rozdílů mezi každou hodnotou a průměrem.

Příklad z běžného života: Pokud budete sledovat teplotní výkyvy během jednoho dne, rozptyl vám pomůže pochopit, jak moc se teploty mění oproti průměrné denní teplotě.

Směrodatná odchylka

Směrodatná odchylka je odmocnina z rozptylu a představuje průměrnou vzdálenost hodnoty od průměru. Je vyjádřena ve stejných jednotkách jako data, což usnadňuje interpretaci.

Příklad z běžného života: V investování je směrodatná odchylka užitečná pro měření volatility akcií - čím vyšší směrodatná odchylka, tím volatilnější akcie.

Variabilita (rozpětí)

Rozpětí je nejjednodušší formou variability, představuje rozdíl mezi největší a nejmenší hodnotou v datové sadě.

Příklad z běžného života: Pokud měříte výšky ve skupině dětí, rozdíl mezi nejvyšším a nejmenším dítětem je rozpětí.

Porovnání středu a variability

Zobrazit kód 
library(ggplot2)
library(gridExtra)

set.seed(123)

# 1. Stejný střed, různá variabilita
data1_low <- rnorm(100, mean = 50, sd = 3)
data1_high <- rnorm(100, mean = 50, sd = 10)

data1 <- data.frame(
  hodnota = c(data1_low, data1_high),
  typ = rep(c("Nízká variabilita (σ=3)", "Vysoká variabilita (σ=10)"), each = 100)
)

p1 <- ggplot(data1, aes(x = hodnota, fill = typ)) +
  geom_histogram(bins = 20, alpha = 0.7, position = "identity") +
  geom_vline(xintercept = 50, color = "darkred", size = 1.5, linetype = "dashed") +
  annotate("text", x = 50, y = 20, label = "Stejný průměr (μ = 50)",
           color = "darkred", fontface = "bold", size = 4, angle = 90, vjust = -0.5) +
  scale_fill_manual(values = c("steelblue", "#E67E22")) +
  labs(
    title = "Stejný střed, RŮZNÁ variabilita",
    subtitle = "Oba soubory mají μ = 50, ale různou směrodatnou odchylku",
    x = "Hodnota",
    y = "Četnost",
    fill = "Datový soubor"
  ) +
  theme_minimal() +
  theme(legend.position = "top")

# 2. Různý střed, stejná variabilita
data2_a <- rnorm(100, mean = 40, sd = 5)
data2_b <- rnorm(100, mean = 60, sd = 5)

data2 <- data.frame(
  hodnota = c(data2_a, data2_b),
  typ = rep(c("Soubor A (μ=40)", "Soubor B (μ=60)"), each = 100)
)

p2 <- ggplot(data2, aes(x = hodnota, fill = typ)) +
  geom_histogram(bins = 20, alpha = 0.7, position = "identity") +
  geom_vline(xintercept = 40, color = "#2ECC71", size = 1.5, linetype = "dashed") +
  geom_vline(xintercept = 60, color = "#9B59B6", size = 1.5, linetype = "dashed") +
  scale_fill_manual(values = c("#2ECC71", "#9B59B6")) +
  labs(
    title = "RŮZNÝ střed, stejná variabilita",
    subtitle = "Oba soubory mají σ = 5, ale různé průměry",
    x = "Hodnota",
    y = "Četnost",
    fill = "Datový soubor"
  ) +
  theme_minimal() +
  theme(legend.position = "top")

# 3. Boxploty - názorná demonstrace
data3 <- data.frame(
  hodnota = c(data1_low, data1_high, data2_a, data2_b),
  skupina = rep(c("μ=50, σ=3", "μ=50, σ=10", "μ=40, σ=5", "μ=60, σ=5"), each = 100)
)
data3$skupina <- factor(data3$skupina, levels = c("μ=50, σ=3", "μ=50, σ=10", "μ=40, σ=5", "μ=60, σ=5"))

p3 <- ggplot(data3, aes(x = skupina, y = hodnota, fill = skupina)) +
  geom_boxplot(alpha = 0.7) +
  stat_summary(fun = mean, geom = "point", shape = 23, size = 4,
               fill = "darkred", color = "darkred") +
  scale_fill_manual(values = c("steelblue", "#E67E22", "#2ECC71", "#9B59B6")) +
  labs(
    title = "Boxploty čtyř souborů dat",
    subtitle = "Červený kosočtverec = průměr, box = variabilita",
    x = "",
    y = "Hodnota"
  ) +
  theme_minimal() +
  theme(
    legend.position = "none",
    axis.text.x = element_text(angle = 20, hjust = 1)
  ) +
  annotate("segment", x = 0.5, xend = 1.5, y = 50, yend = 50,
           color = "darkred", size = 1, linetype = "dotted") +
  annotate("segment", x = 1.5, xend = 2.5, y = 50, yend = 50,
           color = "darkred", size = 1, linetype = "dotted") +
  annotate("text", x = 1, y = 30, label = "Stejný\nstřed",
           color = "darkred", fontface = "bold", size = 3.5) +
  annotate("text", x = 3.5, y = 70, label = "Stejná\nvariabilita",
           color = "darkblue", fontface = "bold", size = 3.5)

gridExtra::grid.arrange(p1, p2, p3, ncol = 1)

Metodologická zásada: Nikdy nereportujte jen střed bez variability!

Jedna z nejzávažnějších chyb v reportování statistik je uvádět pouze charakteristiku středu bez míry variability.

Proč je to problém? Dva datové soubory mohou mít stejný průměr, ale úplně jinou variabilitu: - Skupina A: 50 ± 3 (velmi konzistentní) - Skupina B: 50 ± 30 (extrémně variabilní)

Obě mají průměr 50, ale znamenají něco úplně jiného!

Minimální standard reportování: - Průměr ± směrodatná odchylka (např. “M = 50, SD = 10”) - Nebo: Medián + IQR (např. “Mdn = 48, IQR = 15”) - Ještě lépe: Přidejte vizualizaci (boxplot nebo histogram)

V praxi: Když čtete “průměrná doba čekání je 5 minut”, ptejte se: “Jaká je variabilita?” Může to znamenat “5±1 min” (spolehlivé) nebo “5±20 min” (nespolehlivé)!

Závěr

Charakteristika středu a charakteristika variability jsou základní koncepty ve statistice, které pomáhají popsat a analyzovat data. Charakteristika středu poskytuje informaci o typické hodnotě datové sady, zatímco charakteristika variability nám říká, jak jsou data rozptýlena.
