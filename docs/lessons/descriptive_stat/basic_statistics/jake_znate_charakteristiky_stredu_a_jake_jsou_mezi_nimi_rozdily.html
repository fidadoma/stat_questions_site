Charakteristiky středu

Author

Filip Děchtěrenko

Published

September 20, 2025

Modified

December 6, 2025

Úvod

V oblasti statistiky jsou charakteristiky středu klíčovými prvky, které pomáhají popsat a analyzovat soubor dat. Tyto charakteristiky nám poskytují informace o “typické” hodnotě v datovém souboru. V tomto materiálu si rozebereme hlavní charakteristiky středu: aritmetický průměr, medián a modus. Tyto tři metody mají různé vlastnosti, které je činí vhodné pro různé typy dat a situací.

Aritmetický průměr

Definice

Aritmetický průměr je nejpoužívanější míra středu dat. Spočítá se jako součet všech hodnot v souboru dat dělený počtem těchto hodnot. Vzorec pro aritmetický průměr (značen jako \(\bar{x}\)) je:

\[ \bar{x} = \frac{x_1 + x_2 + \ldots + x_n}{n} \]

kde \(x_1, x_2, \ldots, x_n\) jsou jednotlivé hodnoty datového souboru a \(n\) je počet hodnot.

Příklad z běžného života

Představte si, že jste dostali pět testů zpět a vaše známky byly: 1, 2, 2, 3, a 4. Abyste zjistili, jaká je vaše průměrná známka, sečtete všechny známky dohromady (12) a vydělíte 5 (počet testů). Váš průměr je tedy 2,4.

Výhody a nevýhody

Aritmetický průměr je užitečný, když chceme rychle získat představu o celkovém trendu dat. Je však citlivý na extrémy (outliery). Například, pokud máte známky 1, 1, 1, 1 a 10, průměr bude zkreslený směrem nahoru kvůli jednomu vysokému outlieru.

Zobrazit kód 
library(ggplot2)
library(gridExtra)

# Data bez outliera
data_normal <- data.frame(
  znacka = c("Test 1", "Test 2", "Test 3", "Test 4", "Test 5"),
  hodnota = c(1, 1, 1, 1, 2)
)
mean_normal <- mean(data_normal$hodnota)

# Data s outlierem
data_outlier <- data.frame(
  znacka = c("Test 1", "Test 2", "Test 3", "Test 4", "Test 5"),
  hodnota = c(1, 1, 1, 1, 10)
)
mean_outlier <- mean(data_outlier$hodnota)

p1 <- ggplot(data_normal, aes(x = znacka, y = hodnota)) +
  geom_col(fill = "steelblue", alpha = 0.7) +
  geom_hline(yintercept = mean_normal, color = "darkred",
             linetype = "dashed", size = 1.5) +
  annotate("text", x = 3, y = mean_normal + 0.3,
           label = sprintf("Průměr = %.2f", mean_normal),
           color = "darkred", fontface = "bold", size = 4) +
  labs(
    title = "Bez odlehlé hodnoty",
    x = "",
    y = "Známka"
  ) +
  ylim(0, 11) +
  theme_minimal()

p2 <- ggplot(data_outlier, aes(x = znacka, y = hodnota)) +
  geom_col(aes(fill = hodnota > 5), alpha = 0.7) +
  scale_fill_manual(values = c("steelblue", "#E74C3C")) +
  geom_hline(yintercept = mean_outlier, color = "darkred",
             linetype = "dashed", size = 1.5) +
  annotate("text", x = 3, y = mean_outlier + 0.5,
           label = sprintf("Průměr = %.2f", mean_outlier),
           color = "darkred", fontface = "bold", size = 4) +
  annotate("text", x = 5, y = 11,
           label = "Outlier!",
           color = "#E74C3C", fontface = "bold", size = 4) +
  labs(
    title = "S odlehlou hodnotou",
    x = "",
    y = "Známka"
  ) +
  ylim(0, 11) +
  theme_minimal() +
  theme(legend.position = "none")

gridExtra::grid.arrange(p1, p2, ncol = 2)

Medián

Definice

Medián je střední hodnota datového souboru, která dělí soubor na dvě stejně velké části. Pro jeho určení je třeba data seřadit od nejmenšího po největší. Pokud je počet hodnot lichý, medián je prostřední hodnota; pokud je počet hodnot sudý, medián je průměr dvou prostředních hodnot.

Příklad z běžného života

Pokud máte stejnou sadu známek: 1, 2, 2, 3, 4, medián je 2, protože je to prostřední hodnota v setříděném seznamu. Pokud by vaše známky byly: 1, 2, 2, 3, 4, 5, potom medián by byl průměr dvou prostředních hodnot, tedy (2 + 3)/2 = 2,5.

Výhody a nevýhody

Medián je odolný vůči outlierům, protože není závislý na konkrétních hodnotách, ale na pořadí hodnot. Proto je užitečný v situacích, kdy data obsahují extrémní hodnoty, které by mohly zkreslit výsledky.

Modus

Definice

Modus je hodnota, která se nejčastěji objevuje v datovém souboru. Datová množina může mít jeden mód (unimodální), více módů (multimodální) nebo žádný mód v případě, že se žádná hodnota neopakuje.

Příklad z běžného života

Pokud se podíváme na náš příklad s pěti testy: 1, 2, 2, 3, a 4, modus je 2, protože tato hodnota se objevuje nejčastěji.

Výhody a nevýhody

Modus je užitečný pro kategorie s nepravidelným rozdělením nebo v kvalitativních datech, kde se jiné měry nemusí uplatnit (např. oblíbená barva). Naopak v numerických datech může být nestabilní, zejména pokud je variabilita vysoká nebo počet opakování nízký (u číselných dat typicky modus počítáme na základě histogramu). Je to jediná charakteristika, která lze použít i pro kategorické proměnné.

Porovnání všech třech charakteristik

Zobrazit kód 
library(ggplot2)
library(gridExtra)

# Symetrická data
set.seed(123)
data_sym <- data.frame(
  hodnota = c(rnorm(100, mean = 50, sd = 10))
)
mean_sym <- mean(data_sym$hodnota)
median_sym <- median(data_sym$hodnota)

p1 <- ggplot(data_sym, aes(x = hodnota)) +
  geom_histogram(bins = 20, fill = "steelblue", alpha = 0.7, color = "white") +
  geom_vline(aes(xintercept = mean_sym, color = "Průměr"),
             linetype = "dashed", size = 1.2) +
  geom_vline(aes(xintercept = median_sym, color = "Medián"),
             linetype = "solid", size = 1.2) +
  scale_color_manual(values = c("Průměr" = "#E74C3C", "Medián" = "#2ECC71")) +
  labs(
    title = "Symetrická data",
    subtitle = sprintf("Průměr (%.1f) ≈ Medián (%.1f)", mean_sym, median_sym),
    x = "Hodnota",
    y = "Četnost",
    color = "Charakteristika"
  ) +
  theme_minimal() +
  theme(legend.position = "top")

# Data s pravostranným outlierem (pozitivně zešikmená)
data_skew <- data.frame(
  hodnota = c(rep(40:50, each = 5), rep(51:60, each = 3), 90, 95, 100)
)
mean_skew <- mean(data_skew$hodnota)
median_skew <- median(data_skew$hodnota)
mode_skew <- as.numeric(names(sort(table(data_skew$hodnota), decreasing = TRUE)[1]))

p2 <- ggplot(data_skew, aes(x = hodnota)) +
  geom_histogram(bins = 25, fill = "steelblue", alpha = 0.7, color = "white") +
  geom_vline(aes(xintercept = mean_skew, color = "Průměr"),
             linetype = "dashed", size = 1.2) +
  geom_vline(aes(xintercept = median_skew, color = "Medián"),
             linetype = "solid", size = 1.2) +
  geom_vline(aes(xintercept = mode_skew, color = "Modus"),
             linetype = "dotted", size = 1.2) +
  scale_color_manual(values = c("Průměr" = "#E74C3C",
                                 "Medián" = "#2ECC71",
                                 "Modus" = "#9B59B6")) +
  labs(
    title = "Data s odlehlými hodnotami vpravo",
    subtitle = sprintf("Modus (%.0f) < Medián (%.0f) < Průměr (%.1f)",
                       mode_skew, median_skew, mean_skew),
    x = "Hodnota",
    y = "Četnost",
    color = "Charakteristika"
  ) +
  theme_minimal() +
  theme(legend.position = "top")

# Bimodální data
data_bimodal <- data.frame(
  hodnota = c(rnorm(50, mean = 30, sd = 5), rnorm(50, mean = 70, sd = 5))
)
mean_bimodal <- mean(data_bimodal$hodnota)
median_bimodal <- median(data_bimodal$hodnota)

p3 <- ggplot(data_bimodal, aes(x = hodnota)) +
  geom_histogram(bins = 30, fill = "steelblue", alpha = 0.7, color = "white") +
  geom_vline(aes(xintercept = mean_bimodal, color = "Průměr"),
             linetype = "dashed", size = 1.2) +
  geom_vline(aes(xintercept = median_bimodal, color = "Medián"),
             linetype = "solid", size = 1.2) +
  annotate("text", x = 30, y = 8, label = "Modus 1",
           color = "#9B59B6", fontface = "bold", size = 3.5) +
  annotate("text", x = 70, y = 8, label = "Modus 2",
           color = "#9B59B6", fontface = "bold", size = 3.5) +
  scale_color_manual(values = c("Průměr" = "#E74C3C", "Medián" = "#2ECC71")) +
  labs(
    title = "Bimodální data (dva módy)",
    subtitle = sprintf("Průměr (%.1f) ≈ Medián (%.1f), ale dva módy!",
                       mean_bimodal, median_bimodal),
    x = "Hodnota",
    y = "Četnost",
    color = "Charakteristika"
  ) +
  theme_minimal() +
  theme(legend.position = "top")

gridExtra::grid.arrange(p1, p2, p3, ncol = 1)
Metodologické doporučení: Která charakteristika středu kdy?

Použijte průměr, když:

  • Data jsou přibližně symetrická (ne silně zešikmená)
  • Nejsou extrémní outliers
  • Chcete další výpočty (rozptyl, t-test)
  • Příklad: výška dospělých, výsledky testů

Použijte medián, když:

  • Data jsou zešikmená (příjmy, ceny nemovitostí)
  • Obsahují outliers
  • Potřebujete robustní míru (odolnou vůči extrémům)
  • Máte ordinální proměnnou
  • Příklad: příjmy domácností, doba do události

Použijte modus, když:

  • Máte nominální proměnnou
  • Hledáte nejčastější hodnotu (ne typickou)
  • Data jsou multimodální a chcete identifikovat skupiny
  • Příklad: nejoblíbenější značka auta, nejčastější chybová zpráva

V reportech: Vždy reportujte alespoň 2 míry (např. průměr + medián) - jejich rozdíl vám napoví o zešikmení dat!

Závěr

Charakteristiky středu poskytují základní způsob, jak shrnout a analyzovat data. Každá z těchto mír má své využití v různých kontextech. Průměr je vhodný pro obecné trendy, medián pro datové soubory s outliery a modus pro výskyt konkrétních hodnot. Pro analýzu dat je důležité pochopit, jak aplikovat každý z nich a s jakými výhodami a nevýhodami se potýkají.
