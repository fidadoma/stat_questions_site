Vztahy mezi dvěma proměnnými

Author

Filip Děchtěrenko

Published

September 20, 2025

Modified

December 7, 2025

Úvod

Ve statistice často zkoumáme, jak spolu souvisí dvě nebo více proměnných. Například bychom mohli zkoumat, jak příjem jednotlivců ovlivňuje jejich útraty nebo jak výška člověka souvisí s jeho váhou. Správné pochopení vztahu mezi proměnnými je klíčem k interpretaci a analýze dat.

Typy vztahů mezi dvěma proměnnými

1. Korelační vztah

Korelační vztah indikuje přítomnost určitých vzorců nebo souvislostí mezi proměnnými. Je důležité si však uvědomit, že korelace neznamená kauzalitu. Příkladem může být vztah mezi konzumací zmrzliny a výskytem utonutí – obě hodnoty rostou v létě, ale jedna bezprostředně nezpůsobuje druhou.

Zobrazit kód 
library(ggplot2)
set.seed(123)

# Vytvoření dat - obě proměnné závisí na teplotě (třetí faktor)
mesice <- 1:12
teplota <- c(0, 2, 8, 14, 19, 23, 25, 24, 20, 13, 7, 2)
prodej_zmrzliny <- 10 + 3 * teplota + rnorm(12, 0, 5)
utonuti <- 2 + 0.3 * teplota + rnorm(12, 0, 2)

data <- data.frame(
  mesic = factor(month.name[mesice], levels = month.name),
  prodej_zmrzliny = prodej_zmrzliny,
  utonuti = utonuti
)

ggplot(data, aes(x = prodej_zmrzliny, y = utonuti)) +
  geom_point(size = 3, color = "steelblue") +
  geom_smooth(method = "lm", se = TRUE, color = "red") +
  labs(
    title = "Korelace bez kauzality",
    subtitle = "Zmrzlina a utonutí korelují, ale jedna nezpůsobuje druhou",
    x = "Prodej zmrzliny",
    y = "Počet případů utonutí"
  ) +
  theme_minimal() +
  annotate("text", x = max(data$prodej_zmrzliny) * 0.7, y = max(data$utonuti) * 0.9,
           label = "Skrytý faktor:\nteplota", color = "darkgreen",
           fontface = "bold", size = 4)

2. Kauzální (příčinný) vztah

Kauzální vztah znamená, že jedna proměnná přímo ovlivňuje nebo způsobuje změnu ve druhé proměnné. Tento typ vztahu je obecně těžší prokázat, ale je nezbytný pro správné pochopení příčin a následků. Například zvýšení teploty (příčina) může vést k roztavení sněhu (následek).

Metodologická taxonomie vztahů mezi proměnnými

6 základních typů vztahů:

  1. Pozitivní lineární: X↑ → Y↑ konstantně (r > 0, přímka nahoru)
  2. Negativní lineární: X↑ → Y↓ konstantně (r < 0, přímka dolů)
  3. Nelineární monotónní: X↑ → Y↑ ale ne konstantně (exponenciální, logaritmický)
  4. Nelineární nemonotónní: U-shaped, inverted-U, oscilující vztahy
  5. Žádný vztah: r ≈ 0, body náhodně rozptýlené
  6. Kategoriální vztah: Porovnání průměrů mezi skupinami (ANOVA)

Klíčové rozlišení pro analýzu:

  • Lineární vs nelineární → ovlivňuje volbu modelu
  • Monotónní vs nemonotónní → Spearman funguje jen pro monotónní
  • Korelační vs kauzální → požaduje experimentální design

Praktický postup:

  1. Vždy začněte scatter plotem!
  2. Identifikujte typ vztahu (lineární/nelineární)
  3. Zvolte vhodnou metodu (Pearson/Spearman/jiná)
  4. Nikdy nezaměňujte korelaci za kauzalitu

3. Lineární a nelineární vztahy

Lineární vztah

Ve lineárním vztahu se změna jedné proměnné projeví jako přímo úměrná změna v druhé proměnné. Například, pokud dvakrát zvýšíte množství cvičení, vaše tělesná kondice se zlepší odpovídajícím způsobem. Vztah může být pozitivní nebo negativní.

Nelineární vztah

Nelineární vztah je složitější – změna v jedné proměnné může vést k nelineární nebo nesymetrické změně ve druhé proměnné. Například účinky léku na těle nemusí být lineární – malá dávka může mít jiný poměrný efekt než větší dávka.

Zobrazit kód 
library(ggplot2)
library(gridExtra)
set.seed(123)

# 1. Lineární pozitivní vztah
data_pos <- data.frame(
  x = seq(1, 100, length.out = 100),
  y = 2 * seq(1, 100, length.out = 100) + rnorm(100, 0, 15)
)

p1 <- ggplot(data_pos, aes(x = x, y = y)) +
  geom_point(color = "steelblue", alpha = 0.6) +
  geom_smooth(method = "lm", se = FALSE, color = "red") +
  labs(
    title = "Lineární pozitivní vztah",
    subtitle = "Když X roste, Y také roste",
    x = "Množství cvičení",
    y = "Tělesná kondice"
  ) +
  theme_minimal()

# 2. Lineární negativní vztah
data_neg <- data.frame(
  x = seq(1, 100, length.out = 100),
  y = 200 - 1.5 * seq(1, 100, length.out = 100) + rnorm(100, 0, 15)
)

p2 <- ggplot(data_neg, aes(x = x, y = y)) +
  geom_point(color = "darkred", alpha = 0.6) +
  geom_smooth(method = "lm", se = FALSE, color = "blue") +
  labs(
    title = "Lineární negativní vztah",
    subtitle = "Když X roste, Y klesá",
    x = "Cena benzínu",
    y = "Míra cestování"
  ) +
  theme_minimal()

# 3. Nelineární vztah - kvadratický
data_quad <- data.frame(
  x = seq(0, 10, length.out = 100),
  y = -2 * (seq(0, 10, length.out = 100) - 5)^2 + 50 + rnorm(100, 0, 3)
)

p3 <- ggplot(data_quad, aes(x = x, y = y)) +
  geom_point(color = "darkgreen", alpha = 0.6) +
  geom_smooth(method = "loess", se = FALSE, color = "orange") +
  labs(
    title = "Nelineární vztah - invertovaná parabola",
    subtitle = "Vztah mezi stresem a výkonem",
    x = "Úroveň stresu",
    y = "Výkon"
  ) +
  theme_minimal()

# 4. Nelineární vztah - exponenciální
data_exp <- data.frame(
  x = seq(0, 5, length.out = 100),
  y = exp(seq(0, 5, length.out = 100) * 0.5) + rnorm(100, 0, 2)
)

p4 <- ggplot(data_exp, aes(x = x, y = y)) +
  geom_point(color = "purple", alpha = 0.6) +
  geom_smooth(method = "loess", se = FALSE, color = "darkblue") +
  labs(
    title = "Nelineární vztah - exponenciální",
    subtitle = "Efekt dávky léku",
    x = "Dávka léku",
    y = "Účinek"
  ) +
  theme_minimal()

# 5. Žádný vztah
data_none <- data.frame(
  x = seq(1, 100, length.out = 100),
  y = rnorm(100, 50, 15)
)

p5 <- ggplot(data_none, aes(x = x, y = y)) +
  geom_point(color = "gray40", alpha = 0.6) +
  geom_smooth(method = "lm", se = FALSE, color = "red", linetype = "dashed") +
  labs(
    title = "Žádný vztah",
    subtitle = "Proměnné jsou nezávislé",
    x = "Proměnná X",
    y = "Proměnná Y"
  ) +
  theme_minimal()

# 6. U-shaped vztah
data_u <- data.frame(
  x = seq(0, 10, length.out = 100),
  y = 2 * (seq(0, 10, length.out = 100) - 5)^2 + 10 + rnorm(100, 0, 3)
)

p6 <- ggplot(data_u, aes(x = x, y = y)) +
  geom_point(color = "brown", alpha = 0.6) +
  geom_smooth(method = "loess", se = FALSE, color = "darkgreen") +
  labs(
    title = "Nelineární vztah - U-shaped",
    subtitle = "Vztah mezi věkem a úrazovostí",
    x = "Věk",
    y = "Riziko úrazu"
  ) +
  theme_minimal()

# Uspořádání grafů
gridExtra::grid.arrange(p1, p2, p3, p4, p5, p6, ncol = 2)

Praktické příklady

Příklad 1: Výška a váha

Tento příklad ilustruje lineární vztah. Obecně platí, že čím vyšší je člověk, tím těžší je. Nicméně, je důležité podotknout, že tento vztah neplatí absolutně pro každého, což je důvod, proč se ve statistice zabýváme také variabilitou.

Příklad 2: Cena benzínu a cestování

Cen benzínu a míra automobilového cestování ukazuje kauzální vztah - pokud cena benzínu vzroste, lidé mohou cestovat méně, aby ušetřili peníze.

Příklad 3: Učení se a stres

Učení a stres může být nelineárním vztahem. V mírném množství může stres člověka motivovat (pozitivní efekt), ale příliš mnoho stresu může mít naopak negativní vliv na schopnost učení.

Závěr

Porozumění vztahům mezi proměnnými je základem pro správnou analýzu dat a informované rozhodovací procesy. Přestože vztahy mohou být komplexní a ne vždy přímočaré, statistické techniky nabízí rámec pro jejich pochopení a interpretaci. Ve své praxi se často setkáte jak s kauzálními, tak i ne-kauzálními vztahy, a navíc se budou lišit i charakteristikou, ať už jsou lineární či nelineární.

Podstatné je nejen identifikovat typ vztahu, ale také být schopen kriticky hodnotit a analyzovat podmínky, které tento vztah determinuje.
