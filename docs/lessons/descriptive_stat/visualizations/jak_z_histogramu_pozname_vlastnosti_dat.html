Jak z histogramu poznáme vlastnosti dat?

Author

Filip Děchtěrenko

Published

September 20, 2025

Modified

December 7, 2025

Úvod

Histogram je grafické zobrazení rozložení kvantitativních dat. Pomáhá nám rychle vidět základní vlastnosti dat, jako je tvar rozložení, výskyt extrémních hodnot, symetrii nebo asymetrii a zaměření kolem určité hodnoty. Jedná se o velmi účinný nástroj v průzkumové analýze dat.

Co je histogram?

Histogram je tvořen sadou obdélníků, kde každý reprezentuje frekvenci hodnot ve specifických intervalech (tzv. binty nebo kategorie). Šířka každého bintu se nazývá “šířka binu” a je jednotná pro všechna binty v histogramu. Výška obdélníku odpovídá počtu pozorování (frekvence), která spadají do příslušné kategorie.

Příklad z běžného života

Představme si, že pracujeme jako manažer fitness centra a máme data o váze všech členů tělocvičny. Rádi bychom si udělali představu o tom, jaký je obecný trend váhy u našich členů. Histogram nám pomůže vytvořit přehled o tom, kolik členů spadá do specifických váhových intervalů (například 50-60 kg, 60-70 kg atd.).

Vlastnosti dat z histogramu

Metodologický checklist: Co hledat v histogramu?

1. Tvar rozložení:

  • Symetrické (zvonové) → normální rozložení, parametrické testy OK
  • Šikmé doprava → logaritmická transformace, neparametrické testy
  • Šikmé doleva → zvažte transformaci nebo neparametrické metody
  • Bimodální → možná dvě podskupiny v datech!

2. Centrální tendence:

  • Kde je “vrchol” histogramu? (přibližná hodnota modu/mediánu)
  • Je rozložení symetrické? Pokud ano, průměr ≈ medián

3. Variabilita:

  • Široký histogram → vysoká variabilita (velká SD)
  • Úzký histogram → nízká variabilita (malá SD)

4. Odlehlé hodnoty:

  • Izolované sloupce na krajích?
  • Dlouhé “chvosty” bez dat?

5. Volba bin width:

  • Příliš málo binů → ztrácíte detail
  • Příliš mnoho binů → šum, ztráta celkového obrazu
  • Doporučení: Zkuste 3-4 různé šířky binů!

VŽDY začněte analýzu vizualizací! Histogram vám řekne, zda jsou splněny předpoklady parametrických testů.

Tvar rozložení

  • Symetrické rozložení: Pokud je histogram přibližně symetrický, data jsou rovnoměrně rozložena kolem středové hodnoty. V případě perfektní symetrie bude histogram tvořit tvar zvonu (normální rozložení).

  • Asymetrické (šikmé) rozložení: Když většina dat je nakupena na jedné straně histogramu a “chvost” rozložení směřuje k druhé straně, mluvíme o šikmém rozložení.

    • Šikmá doprava (kladná šikmost): Chvost je na pravé straně. Například příjmová data často mají kladnou šikmost, protože existuje několik velmi vysokých příjmů, zatímco většina lidí má nižší příjmy.
    • Šikmá doleva (záporná šikmost): Chvost je na levé straně. Příklad může být doba dokončení úkolu, kdy většina lidí dokončuje úkoly rychleji než několik lidí, kteří je dokončují velmi pomalu.

Střední hodnota a šířka rozložení

  • Střední hodnota (průměr): Je to hodnota, kolem které se data koncentrují. V histogramu můžete intuitivně odhadnout, kde leží střední hodnota, protože to obvykle bude tam, kde má histogram nejvyšší obdélník.

  • Variabilita (rozptyl a směrdatná odchylka): V histogramu se variabilita dat odráží ve šířce a tvaru histogramu. Úzký a vysoký histogram naznačuje, že data mají nízkou variabilitu. Široký a plochý histogram naznačuje vysokou variabilitu.

Přítomnost extrémních hodnot

Histogram nám také může pomoci identifikovat extrémní hodnoty, což jsou hodnoty, které se významně liší od ostatních v datasetu. Ty se často objevují jako izolované obdélníky v histogramu s malou výškou na jednom z konců rozložení.

Příklad z běžného života

Možná analyzujeme čas, který studenti potřebují na dokončení testu. Většina studentů rozloží svou dobu dokončení kolem průměru. Nicméně, pokud existuje několik studentů, kteří dokončili test mnohem rychleji nebo pomaleji než všichni ostatní, tyto časy se projeví jako extrémní hodnoty v histogramu.

Praktická práce s histogramem

Díky histogramu se můžete rychle seznámit s vlastnostmi vašich dat. Při analýze dat doporučujeme vždy začít s vizualizací pomocí histogramu, abyste získali základní intuitivní pochopení o rozložení vašich dat. To vám pomůže rozhodovat, jaké další analýzy bychom měli provést nebo jaké statistické modely použít.

Pamatujte, že posouzení histogramu je často subjektivní a může záviset na nastavení šířky binu. Různé nastavení šířky může vést k odlišným interpretacím, proto je důležité si být vědom toho, jak to může ovlivnit váš pohled na data.

Vizualizace různých typů histogramů

Pro lepší pochopení si ukážeme příklady různých typů rozložení dat pomocí histogramů:

Zobrazit kód 
library(ggplot2)
library(gridExtra)
set.seed(123)

# 1. Symetrické (normální) rozložení
data_symmetric <- data.frame(
  hodnota = rnorm(1000, mean = 50, sd = 10),
  typ = "Symetrické rozložení"
)

# 2. Pravostranně šikmé (kladná šikmost)
data_right_skew <- data.frame(
  hodnota = exp(rnorm(1000, mean = 3.5, sd = 0.5)),
  typ = "Šikmé doprava (kladná šikmost)"
)

# 3. Levostranně šikmé (záporná šikmost)
data_left_skew <- data.frame(
  hodnota = 100 - exp(rnorm(1000, mean = 3.5, sd = 0.5)),
  typ = "Šikmé doleva (záporná šikmost)"
)

# 4. Nízká variabilita
data_low_var <- data.frame(
  hodnota = rnorm(1000, mean = 50, sd = 3),
  typ = "Nízká variabilita (úzké rozložení)"
)

# 5. Vysoká variabilita
data_high_var <- data.frame(
  hodnota = rnorm(1000, mean = 50, sd = 20),
  typ = "Vysoká variabilita (široké rozložení)"
)

# 6. Data s odlehlými hodnotami
data_outliers <- data.frame(
  hodnota = c(rnorm(950, mean = 50, sd = 8),
              rnorm(50, mean = 100, sd = 5)),
  typ = "Přítomnost odlehlých hodnot"
)

# Funkce pro vytvoření histogramu
create_histogram <- function(data, title) {
  ggplot(data, aes(x = hodnota)) +
    geom_histogram(bins = 30, fill = "steelblue", color = "white", alpha = 0.7) +
    labs(title = title, x = "Hodnota", y = "Četnost") +
    theme_minimal() +
    theme(plot.title = element_text(size = 10, face = "bold"))
}

# Vytvoření jednotlivých grafů
p1 <- create_histogram(data_symmetric, "Symetrické rozložení")
p2 <- create_histogram(data_right_skew, "Šikmé doprava (kladná šikmost)")
p3 <- create_histogram(data_left_skew, "Šikmé doleva (záporná šikmost)")
p4 <- create_histogram(data_low_var, "Nízká variabilita")
p5 <- create_histogram(data_high_var, "Vysoká variabilita")
p6 <- create_histogram(data_outliers, "S odlehlými hodnotami")

# Uspořádání do mřížky
gridExtra::grid.arrange(p1, p2, p3, p4, p5, p6, ncol = 2)

Vliv šířky binu na interpretaci

Ukážeme si, jak různá šířka binů ovlivňuje vzhled histogramu:

Zobrazit kód 
set.seed(123)
data <- data.frame(hodnota = rnorm(500, mean = 50, sd = 10))

p1 <- ggplot(data, aes(x = hodnota)) +
  geom_histogram(bins = 10, fill = "steelblue", color = "white", alpha = 0.7) +
  labs(title = "Málo binů (10)", x = "Hodnota", y = "Četnost") +
  theme_minimal()

p2 <- ggplot(data, aes(x = hodnota)) +
  geom_histogram(bins = 30, fill = "steelblue", color = "white", alpha = 0.7) +
  labs(title = "Střední počet binů (30)", x = "Hodnota", y = "Četnost") +
  theme_minimal()

p3 <- ggplot(data, aes(x = hodnota)) +
  geom_histogram(bins = 100, fill = "steelblue", color = "white", alpha = 0.7) +
  labs(title = "Mnoho binů (100)", x = "Hodnota", y = "Četnost") +
  theme_minimal()

gridExtra::grid.arrange(p1, p2, p3, ncol = 1)

Závěr

Histogram je klíčovým nástrojem pro pochopení rozložení dat. Z histogramu můžeme rychle identifikovat tvar rozložení (symetrické vs. šikmé), variabilitu dat (úzké vs. široké rozložení), přítomnost odlehlých hodnot a koncentraci dat kolem střední hodnoty. Je důležité si uvědomit, že volba šířky binu může významně ovlivnit vizuální interpretaci dat, proto je vhodné vyzkoušet několik různých nastavení.
